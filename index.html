💻 Script Python en Ligne de Commande & Export

Un script Python complet est disponible dans ce dossier pour calculer les distances à la seconde près et générer des exports en direct :

# 1. Calcul instantané actuel : python3 astro_distances.py --lang fr # 2. Calcul pour une date et heure précise : python3 astro_distances.py --date "2000-01-01 12:00:00" --lang fr # 3. Mode temps réel dans le terminal (mise à jour chaque seconde) : python3 astro_distances.py --live --lang fr # 4. Calcul jour par jour entre 2000 et aujourd'hui exporté en CSV : python3 astro_distances.py --range 2000-01-01 2026-11-16 --step day --output distances_2000_2026.csv
